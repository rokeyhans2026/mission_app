# MATE — 다중 협동 로봇 임무 제어 시스템 (Multi-Agent Task Execution)

> **M**ulti-**A**gent **T**ask **E**xecution · ROS 기반 협동 로봇 플랫폼

---

## 개요

**MATE**는 복수의 협동 로봇(코봇)이 하나의 임무를 나누어 수행하는 다중 로봇 임무 제어 시스템입니다.
서로 다른 역할을 가진 로봇들이 ROS 네트워크를 통해 실시간으로 협업하며, 물류 피킹, 공장 생산라인 보조, 실내 탐사 등 다양한 시나리오를 지원합니다.

### 주요 시나리오

- 🤖 **물류 피킹**: AGV(이동 로봇)와 매니퓰레이터(팔 로봇)가 협업하여 주문 상품을 자동으로 집어 나르는 임무
- 🏭 **생산라인 보조**: 고정형 코봇이 부품 조립, 무거운 물건 리프팅 등 반복 작업을 담당
- 🗺️ **실내 탐사**: 여러 이동 로봇이 영역을 분할 탐색하여 지도를 병합

## 시스템 구조

```
┌─────────────────────────────────────────────────────────┐
│                     임무 스케줄러                        │
│              mission_app (중앙 제어 노드)                 │
└───────────────┬─────────────────────┬───────────────────┘
                │  임무 분배 (task)    │  상태 수집 (status)
   ┌────────────▼─────────┐   ┌────────▼────────────┐
   │  매니퓰레이터 에이전트 │   │     AGV 에이전트      │
   │  (arm_robot)         │   │  (mobile_robot)     │
   └────────────┬─────────┘   └────────┬────────────┘
                │                      │
        ┌───────▼────────┐     ┌───────▼────────┐
        │  MoveIt /      │     │  Nav2 /        │
        │  동작 계획       │     │  자율 주행      │
        └────────────────┘     └────────────────┘
```

- **중앙 임무 스케줄러**: 전체 임무를 분해하고 각 로봇에게 작업을 배분
- **에이전트 노드**: 개별 로봇의 동작을 담당하는 서브 노드
- **통신**: ROS 토픽/액션 기반 실시간 협업

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 임무 분해 & 분배 | 하나의 큰 임무를 서브태스크로 분해하여 에이전트에게 자동 배분 |
| 협업 조정 | 로봇 간 작업 완료 신호를 기반으로 다음 동작 동기화 |
| 상태 모니터링 | 각 로봇의 진행률·베터리·오류 상태를 실시간 수집 |
| 충돌 회피 | 작업 영역이 겹칠 때 우선순위 기반으로 동작 순서 결정 |
| 장애 복구 | 특정 로봇이 실패하면 다른 로봇이 해당 작업을 인수 |

## 기술 스택

- **ROS 2 (Humble)** — 로봇 소프트웨어 플랫폼
- **MoveIt 2** — 매니퓰레이터 역기구학 및 동작 계획
- **Nav2** — 이동 로봇 자율 주행
- **TF2** — 좌표계 변환 및 로봇 간 상대 위치 인식
- **Python / C++** — 노드 구현

## 빠른 시작

```bash
# 1. 의존성 설치
rosdep install --from-paths src --ignore-src -r -y

# 2. 빌드
colcon build --symlink-install
source install/setup.bash

# 3. 중앙 임무 스케줄러 실행
ros2 launch mission_app mission.launch.py

# 4. (선택) Gazebo 시뮬레이션 실행
ros2 launch mission_app simulation.launch.py
```
